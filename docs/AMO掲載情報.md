# AMO 掲載情報

addons.mozilla.org へ**公開（listed）**で登録するときに、フォームへ貼り付ける内容。
文面を変えたらこのファイルも更新する。

## 登録の流れ

1. https://addons.mozilla.org/developers/ にログイン
2. 「新しいアドオンを登録」
3. 配布方法で **「Mozilla で配布する」** を選ぶ（公開審査に回る）
4. `dist\CertainlyOpenYoutubeShorts-<版>.zip` をアップロード
5. 下記の内容を各欄に入力
6. 送信して審査を待つ

ソースコードの提出は不要（難読化・minify をしていないため）。
公開審査は自動チェックのみで通ることも、人手のレビューに回ることもある。

## 概要（Summary / 250 文字以内）

```
YouTube のチャンネル Shorts 一覧で、クリックしたものと違う Short が再生される問題を直します。画面が真っ黒で音声だけ流れる症状にも対処します。さらに、クリックした後の再生順を、一覧で選んでいた並び順（新しい順・人気の動画・古い順）のまま保ちます。設定は不要です。
```

## 詳細説明（Description）

```
チャンネルの Shorts 一覧からサムネイルをクリックしたのに、別の Short が再生されてしまう。
一度は正しい URL が開くのに、再生されないまま次の動画へ飛んでしまう。
Firefox でこの症状に悩まされている方のための拡張機能です。

■ 直すこと

1. クリックした Short と違う動画が再生される
   リンク自体は正しく、原因は SPA（ページ内遷移）の途中で
   プレーヤーが自分の位置を見失うことにあります。
   通常のページ遷移で開くことで、この経路そのものを避けます。

2. 画面が真っ黒で音声だけ流れる
   映像は正しく読み込まれているのに、表示位置だけが大きくずれている状態です。
   検出して画面の中央に戻します。

3. 再生順が一覧の並びと変わってしまう
   一覧でクリックした時点の並び順（新しい順・人気の動画・古い順）を覚えておき、
   次へ送る操作をその順で行います。一覧を最後まで見進めることができます。

■ 使い方

インストールするだけです。設定画面はありません。

ひとつだけお願いがあります。この拡張機能は Shorts を通常のページ遷移で開くため、
Firefox の自動再生ブロックが働いて再生が止まることがあります。
YouTube を開いた状態でアドレスバー左端のアイコンをクリックし、
「自動再生」を「音声と動画を許可する」に設定してください。

■ プライバシー

いかなる情報も収集・送信しません。
動作に必要な情報（一覧の並び順など）は、タブを閉じると消える形で
お使いの端末の中だけに保存されます。
動作するのは www.youtube.com のみで、他のサイトでは一切動きません。

■ 既知の制限

Shorts を 1 本送るたびにページ遷移が発生するため、
何も入れていない状態に比べて動作が遅くなります。
これは不具合の原因である SPA 遷移を避けることと引き換えの仕様です。

ソースコードは GitHub で公開しています。
```

## スクリーンショット

この拡張機能には UI が無いため、症状と結果が伝わる画像を用意する。
最低 1 枚、できれば 3 枚。推奨サイズは横 1280px 以上。

| # | 内容 | 撮り方 |
| --- | --- | --- |
| 1 | チャンネルの Shorts 一覧 | 並び替えのタブ（新しい順・人気の動画・古い順）が写る位置で撮る |
| 2 | クリックした Short が正しく開いた状態 | 1 で撮った一覧のどれかをクリックした直後。タイトルが一致していることが分かるように |
| 3 | 自動再生の許可設定 | アドレスバー左端のアイコンを開き「自動再生」の項目が見える状態 |

3 枚目は、利用者が最初につまずく設定なので入れておくと問い合わせが減る。

## 審査で聞かれそうなこと

| 想定 | 答え |
| --- | --- |
| なぜ YouTube のリンク動作を書き換えるのか | Firefox 固有の不具合の回避。SPA 遷移でのみ再現し、通常のページ遷移では再現しない |
| なぜ YouTube へ追加のリクエストを送るのか | チャンネル一覧の続きを取得して再生順を保つため。利用者が一覧をスクロールするのと同じ経路 |
| データ収集は | 無し。`data_collection_permissions` に `none` を宣言済み |
| 難読化・外部スクリプトの読み込みは | 無し。ソースはそのまま同梱 |
