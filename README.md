# CertainlyOpenYoutubeShorts

**Youtube Shorts一覧から選択したShortを再生します。**

クリックしたShortと別の動画が再生されることを防ぎます。

## インストール

Firefox Add-ons (AMO) で公開申請中です。公開されたらここにリンクを掲載します。

それまでは [開発者向けの手順](docs/開発者向け.md#開発中の読み込み) で読み込めます。

## 使い方


### 1. 自動再生を許可する

Firefox設定でYoutube動画の自動再生を許可する。

1. YouTube を開いた状態で、アドレスバー左端のアイコンをクリック
2. **自動再生**の**音声と動画を許可**をクリック
3.  **「音声と動画を許可する」** を選ぶ
  
![](https://github.com/user-attachments/assets/4ccad2fb-22d6-468f-b890-0d9b670c8ff7)

設定画面から行う場合は、設定 → プライバシーとセキュリティ → 許可設定 → 自動再生「設定...」で
`https://www.youtube.com` を「音声と動画を許可する」で追加してください。

### 2. 機能の適用

開いている YouTube のタブを `Ctrl+R` で再読み込みしてください。
新しく開いたページには自動で適用するため、再読み込みする必要はありません。


## 備考

**Shorts を スクロールたびにページの読み込みが発生するため、素の状態より動作が遅くなる場合があります。**

## プライバシー

**いかなる情報も収集・送信しません。**

動作に必要な情報（一覧の並び順など）は、タブを閉じると消える形でお使いの端末の中だけに保存されます。
動作するのは `www.youtube.com` のみで、他のサイトでは一切動きません。

詳しくは [プライバシーポリシー](PRIVACY.md) をご覧ください。
