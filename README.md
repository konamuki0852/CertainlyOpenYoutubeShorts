# CertainlyOpenYoutubeShorts

**クリックした Shorts を、確実にその Shorts として開く Firefox 拡張機能です。**

YouTube のチャンネル Shorts 一覧でサムネイルをクリックしたのに、
別の Short が再生されてしまう。Firefox で起きるこの問題を直します。

## 直すこと

### 1. クリックしたものと違う Short が再生される

一度は正しい動画のページが開くのに、再生されないまま別の Short に切り替わってしまう症状です。
リンク自体は正しく、ページ内で切り替える処理の途中で行き先を見失うことが原因です。
この拡張機能は、通常のページ移動で開くことでこれを回避します。

### 2. 画面が真っ黒で音声だけ流れる

映像は正しく読み込まれているのに、表示位置だけが大きくずれてしまう症状です。
検出して画面の中央に戻します。

### 3. 再生順が一覧の並びと変わってしまう

一覧でクリックした時点の並び順（**新しい順・人気の動画・古い順**）を覚えておき、
次へ送る操作をその順で行います。一覧を最後まで順番に見進められます。

## インストール

Firefox Add-ons (AMO) で公開申請中です。公開されたらここにリンクを掲載します。

それまでは [開発者向けの手順](docs/開発者向け.md#開発中の読み込み) で読み込めます。

## 使う前にひとつだけ設定してください

この拡張機能は Shorts を通常のページ移動で開きます。
そのため Firefox の自動再生ブロックが働き、**動画が止まったまま開くこと**があります。

1. YouTube を開いた状態で、アドレスバー左端のアイコンをクリック
2. 「自動再生」→ **「音声と動画を許可する」** を選ぶ

設定画面から行う場合は、設定 → プライバシーとセキュリティ → 許可設定 → 自動再生「設定...」で
`https://www.youtube.com` を「音声と動画を許可する」で追加してください。

## 使い方

インストール後は特に操作は要りません。設定画面もありません。

Shorts を見ているときの操作は普段どおりです。

| 操作 | 動き |
| --- | --- |
| マウスホイールを下へ | 一覧の次の Short |
| マウスホイールを上へ | 一覧の前の Short |
| `↓` キー | 一覧の次の Short |
| `↑` キー | 一覧の前の Short |

一覧以外（ホームや検索結果など）から開いた Short では、YouTube のいつもの動作のままです。

## 既知の制限

**Shorts を 1 本送るたびにページの読み込みが発生するため、素の状態より動作が遅くなります。**
これは不具合の原因を避けることと引き換えの仕様です。

テンポよく送りたい場合は、`cys.js` の `自前で順送り` を `false` にすると
順送りの機能だけを切って、YouTube のおすすめ順に戻せます。

## うまく動かないとき

1. `about:addons` でこの拡張機能が**有効**になっているか確認してください
2. YouTube のタブを再読み込み（`Ctrl+R`）してください。
   拡張機能は、すでに開いているページには後から適用されません
3. それでも直らない場合は、[イシュー](https://github.com/konamuki0852/CertainlyOpenYoutubeShorts/issues)でお知らせください

## プライバシー

**いかなる情報も収集・送信しません。**

動作に必要な情報（一覧の並び順など）は、タブを閉じると消える形でお使いの端末の中だけに保存されます。
動作するのは `www.youtube.com` のみで、他のサイトでは一切動きません。

詳しくは [プライバシーポリシー](PRIVACY.md) をご覧ください。
